# 💰 Controle de Gastos

Aplicativo de console em **Java** para registrar e acompanhar seus gastos do dia a dia simples, rápido e com os dados salvos em arquivo.

![Java](https://img.shields.io/badge/Java-21-orange?logo=openjdk&logoColor=white)
![License](https://img.shields.io/badge/licença-MIT-blue)

## Funcionalidades

- ➕ Adicionar, listar, editar e remover despesas
- 📊 Relatório com o total gasto por categoria
- 💾 Salvamento automático em arquivo (os dados não se perdem)

## Como executar

Requer o **Java (JDK 17+)** instalado.

```bash
git clone https://github.com/SEU-USUARIO/controle-gastos.git
cd controle-gastos
javac *.java
java Main
```

## Tecnologias

Java 21 · `java.time` (datas) · `java.nio.file` (arquivos) · sem bibliotecas externas.
